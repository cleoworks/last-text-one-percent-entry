The last text message a phone sends at one percent battery: after four years of replying in 0.3 seconds, it finally leaves its owner on read. One sentence, 107 characters, in the dying phone's own voice. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

Writes the message to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic, standard library only, no network.
